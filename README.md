# المدونة

تطبيق عربي RTL لليوميات الخاصة والمشاركة الاختيارية والمهام والمقاضي والطلبات اللطيفة، مبني على Vite وSupabase. لا يوفر رفع صور أو فيديو أو ملفات أو صوت. التقويم الافتراضي أم القرى، مع يوم وأسبوع وشهر وسنة، وتقويم ميلادي بديل.

## تشغيل محلي

استخدم Node.js 22 أو أحدث. نفّذ `npm ci` ثم انسخ `.env.example` إلى `.env.local` وضع عنوان المشروع ومفتاحه **القابل للنشر فقط**. ثم `npm run dev`، و`npm test`، و`npm run build`.

لا تضع service_role أو مفاتيح سرية أو العنوانين الشخصيين في المستودع. قائمة البريد المسموح به محفوظة في قاعدة البيانات فقط. بيانات الجولة التجريبية افتراضية، ولا تُحفظ أو تُرسل إلى الخادم. جلسة الدخول تحفظ في sessionStorage؛ إغلاق التبويب يتطلب تسجيل الدخول مجددًا.

## النشر

الإصدار المبني معدّ لـGitHub Pages: الفرع main وجذر المستودع، تحت /almudawana/. تعذرت الكتابة عبر اتصال GitHub، لذا رُفعت ملفات البناء عبر المتصفح، وأُرفق المصدر القابل للتحرير في source.zip. النسخة المحلية المنظمة تحتوي ملفات المصدر كاملة، والمجلد docs نسخة من البناء. ملف .nojekyll يمنع تحويل Jekyll. إعادة البناء: `npm run build` ثم ارفع محتويات dist إلى جذر المستودع. التهيئة القابلة للنشر موجودة في ملفات JavaScript المبنية وهي عامة بطبيعتها؛ الحماية تفرضها RLS في الخادم.

## قاعدة البيانات

تستخدم النسخة الحالية قاعدة مشروع Lovable الحالي فقط. تعذر إنشاء مشروع Supabase مجاني مستقل لأن الحساب بلغ حد المشاريع المجانية. لا توجد ترقية أو اشتراكات جديدة. استمرار تشغيل Lovable Cloud يخضع لحصصه الحالية؛ لا يمثل هذا ضمان استضافة بلا حدود.

`database/reference-schema.sql` نسخة مرجعية من المخطط السابق، دون قائمة بريد حقيقية. `database/hardening.sql` طبقة التقوية المطبقة مرة واحدة على القاعدة الحالية؛ ليست عملية ترحيل قابلة للتكرار. لا تنفذها مرة ثانية على القاعدة نفسها. عند الانتقال لقاعدة مستقلة جديدة راجع المخطط، أضف البريدين خارج Git، واضبط قوالب البريد لتحتوي {{ .Token }} ثم اختبر الدخول الفعلي.

تتطلب كل السياسات عضوية مرتبطة ببريد مؤكد ومسموح. اليوميات خاصة افتراضيًا، والمسودات لا يقرؤها الشريك. مشاركة قائمة تتيح للطرفين تعديل عناصرها فقط، بينما ملكية القائمة وتدوينات صاحبها لا تتغير. إلغاء المشاركة يخفي التدوينة والتعليقات والتفاعلات ويزيل إشعاراتها. النسخ التي قرأها الطرف الآخر سابقًا لا يمكن سحبها من ذاكرته.

## الخط

لا تتضمن النسخة ملفات خطوط أو روابط CDN. يحاول CSS استخدام خط ثمانية المثبّت محليًا. حمّله من https://font.thmanyah.com وراجع https://font.thmanyah.com/licenses. عند عدم تثبيته يستخدم المتصفح خطه الافتراضي مؤقتًا؛ لذلك لا ندّعي أن شرط «ثمانية فقط» مكتمل على الأجهزة غير المهيأة. يلزم تثبيت الخط لكل جهاز أو إذن صريح من مالكه لمسار تضمين مناسب.

## التحقق

`npm test` يشغل اختبارات التواريخ واختبار PostgreSQL فعليًا عبر PGlite، مع تبديل دور authenticated وauth.uid لاختبار الطرفين، والمسودات، والتعليقات، والمهام، والانتحال، وإلغاء المشاركة، ومنع حساب ثالث. شُغّلت المجموعة الأساسية أيضًا على قاعدة Lovable الفعلية داخل معاملة ROLLBACK دون ترك الحسابات والبيانات الاختبارية. أضيفت محليًا اختبارات منع كتابة مهام القائمة الخاصة وتزوير الإشعارات؛ لم تُعد هذه الإضافات على السحابة بسبب حد الاستعلامات المجاني المؤقت. الاختبار ليس بديلًا عن دخول المستخدمين من جهازين والتحقق من وصول البريد والمزامنة الفعلية.

Service Worker يخزّن غلاف التطبيق العام فقط، ويستثني Auth وواجهات قاعدة البيانات. لا يوجد حفظ لليوميات دون اتصال أو صف تغييرات مؤجلة. عند انقطاع الشبكة لا تنجح عمليات الحفظ.
